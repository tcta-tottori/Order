# Order View（発注ビューア）

Excel の発注ブック（`○○Ver.6.xlsm` など）をスマートフォンの縦画面で見やすく表示する、インストール不要の Web アプリ（PWA）です。
ファイルはスマホ内（iCloud Drive / Google ドライブ / ファイルアプリ等）から選択し、ブラウザ内だけで解析します。サーバーへの送信はありません。

## 表示対象のシート

**「直近」と、「所要(調整)」より右側にあるシート**（ハコ_直近 / ハコ / ゴウダ / パット_直近 / 各業者…）を表示します。
「所要(調整)」が無い場合は「直近」以降すべてが対象です。設定で「対象外のシートも表示」を ON にすると、設定・在庫警告・所要などもメニューに出せます（選択時に読み込み）。

## 画面構成

- **左上 ≡（ハンバーガー）**: 左からメニューが開き、シートの一覧・読み込みページ・設定（下部固定）・バージョン情報を選べます。
- **右下 ✎（編集ボタン）**: 下からメニューが開き、表示方法（日別 / カード / 表）の切り替え、検索、表の列の表示/非表示を編集できます。
- 配色は Excel の緑を基調にしています。

## 3 つの見方

| 見方 | 内容 |
| --- | --- |
| 日別 | 「直近」のような **出荷日ごとのブロック × ライン** 構成のシートを自動判定し、日付を選ぶとライン別に機種・色・数量・備考・残業状況をカードで表示 |
| カード | 見出し行のある一覧シートを 1 行 = 1 カードで表示。品番・品名をタイトルに、日付列は「日別」チップ（0 と空欄は省略）にまとめます。「所要」のように 所要/発注/在庫 が連続する行は 1 枚に統合 |
| 表 | 業者シートでは **品番・品名（と区分）を左に固定** し、他の属性列は初期状態で非表示（✎ メニューから列ごとに表示/非表示を切替、シートごとに記憶）。「当日」から先の日付列は横スクロールで閲覧。今日の日付列は強調表示。その他のシートは Excel のレイアウトどおり（固定枠・結合セル・塗り色・非表示行列を反映）。ピンチで拡大縮小、セルをタップで品番・区分・日付つきの全文表示 |

そのほか: 全文検索（行・カードを絞り込み）、文字サイズ変更、空行・空列の省略、行番号・列記号の表示、前回ファイルの端末内保存（IndexedDB）と起動時の自動再表示、オフライン動作（Service Worker）。

## 使い方

1. `index.html` を HTTPS で公開します（GitHub Pages なら `Settings → Pages → Branch` を選ぶだけ）。
2. スマホのブラウザで開き、「ファイルを選択」から `.xlsm` / `.xlsx` を選びます。
3. 「ホーム画面に追加」するとアプリのように起動できます。

ローカルで試す場合:

```bash
python3 -m http.server 8080
# → http://localhost:8080/
```

## 構成

```
index.html            画面
css/app.css           スタイル（スマホ縦画面優先）
js/app.js             画面ロジック（日別 / カード / 表）
js/xlsx-lite.js       xlsx/xlsm の軽量リーダー（値・書式・塗り・結合・固定枠・非表示）
js/numfmt.js          Excel 表示形式の整形（m"月"d"日" / aaa 曜日 / ggge 元号 など）
vendor/jszip.min.js   zip 展開（MIT）
sw.js / manifest.webmanifest / icons/   PWA
```

依存ライブラリは JSZip のみで、ビルド工程はありません。対象シートだけを解析するため、数十シート・数千行のブックでも数秒で開きます。

## 制限

- 旧形式 `.xls` は非対応（`.xlsx` / `.xlsm` で保存してください）。
- 数式は Excel が保存した計算結果を表示します（再計算はしません）。
- 条件付き書式・罫線・グラフ・画像は表示しません。
