# Order View（発注ビューア）

Excel の発注ブック（`○○Ver.6.xlsm` など）をスマートフォンの縦画面で見やすく表示する、インストール不要の Web アプリ（PWA）です。
ファイルはスマホ内（iCloud Drive / Google ドライブ / ファイルアプリ等）から選択し、ブラウザ内だけで解析します。サーバーへの送信はありません。

## 表示対象のシート

**「直近」と、「所要(調整)」より右側にあるシート**（ハコ_直近 / ハコ / ゴウダ / パット_直近 / 各業者…）を表示します。
「所要(調整)」が無い場合は「直近」以降すべてが対象です。設定で「対象外のシートも表示」を ON にすると、設定・在庫警告・所要などもメニューに出せます（選択時に読み込み）。

## 画面構成

- **ヘッダー**: 左にシート名、その下に現在のフィルター状況（検索・列フィルター・L/T フィルター・変更件数）、右に行数。
- **左上 ≡（ハンバーガー）**: 左からメニューが開き（開くと ✕ に変わり、押すと閉じます）、シートの一覧・変更内容・読み込みページ・設定・バージョン情報を選べます。アプリ名は下部に小さく表示。
- **右下 ✎（編集ボタン）**: 下からメニューが開き、表示方法（日別 / カード / 表）の切り替え、検索、列フィルターの解除、L/T フィルター、表の列の表示/非表示を編集できます。
- 配色は Excel の緑を基調にしています。

## 数量の変更と共有

- 業者シートの表で **「所要」「発注」の数量セルをタップ** すると数量を変更できます（±ボタン、最小ロット単位の加減、0 にする）。変更セルはオレンジ、その影響で再計算された **在庫（当日以降）は青** で表示され、元の値も小さく残ります。
- 変更は端末に記憶され、元の Excel ファイルには手を加えません。
- メニューの **「変更内容」** に全変更が一覧され、個別の取り消し・全破棄ができます。「Excel を添付してメール（共有）」で変更一覧の Excel（見やすい「変更一覧」＋マクロ反映用の「取込用」シート）を作成し、端末の共有機能からメール等に添付できます。共有に対応していない環境では Excel を保存し、件名・本文入りのメール作成画面を開きます。

## 発注L/T の補完

「発注L/T」が 0 または空白の品番は、同じシート内の **同じ代表機種 → 品名が近い（先頭が一致する）品番 → シート内の最長 L/T** の順で L/T を推定し、L/T×2 フィルターに使います。✎ メニューに推定件数を表示します。

## 画面の向き

設定の「画面の向き」で **端末の設定に従う / 回転しない（縦固定） / 横向き固定** を選べます。横向きでは分割ビューが左右に並び、カードや日別表示が 2 列になります（PWA として追加している場合は OS の回転ロック、それ以外はアプリ内で画面を回転します）。

## 3 つの見方

| 見方 | 内容 |
| --- | --- |
| 日別 | 「直近」のような **出荷日ごとのブロック × ライン** 構成のシートを自動判定し、日付を選ぶとライン別に機種・色・数量・備考・残業状況をカードで表示 |
| カード | 見出し行のある一覧シートを 1 行 = 1 カードで表示。品番・品名をタイトルに、日付列は「日別」チップ（0 と空欄は省略）にまとめます。「所要」のように 所要/発注/在庫 が連続する行は 1 枚に統合 |
| 表（直近） | 「直近」では **出荷日 × ライン のマトリクス**。各セルに機種・色・数量のチップと残業/定時/停止のバッジ、今日の列を強調。6 件以上は「+N件を表示」で展開。元の Excel レイアウトは「Excel」ビューで確認可 |
| 表 | 業者シートでは **品番・品名（と区分）を左に固定** し、他の属性列は初期状態で非表示（✎ メニューから列ごとに表示/非表示を切替、シートごとに記憶）。「当日」から先の日付列は横スクロールで閲覧。今日の日付列は強調表示。その他のシートは Excel のレイアウトどおり（固定枠・結合セル・塗り色・非表示行列を反映）。ピンチで拡大縮小、セルをタップで品番・区分・日付つきの全文表示 |

**フィルター（業者シートの表・カード）**: Excel と同じように **表の見出しセルをタップ** すると、その列の値一覧（件数つき）が開き、複数選択・値の検索・「空白・0 を除く」・数値の範囲（以上/以下）で絞り込めます。日付列では「この日に発注あり / 所要あり」を選ぶと、その日に発注（所要）がある品番の所要・発注・在庫の 3 行をまとめて表示できます。複数の列に同時に設定でき、絞り込み中の見出しは緑にフィルターマークが付きます。✎ メニューには設定中のフィルターが一覧表示され、個別／一括で解除できます。「L/T×2 フィルター」（発注L/T×2 営業日以内に所要・発注がない品番を隠す。初期状態 ON）は ✎ メニューで切り替えます。日付見出しは上段「9/7」、下段が曜日で、土日は色分け、今日は緑で強調されます。

**分割ビュー**: ✎ メニューの「分割ビュー」を ON にすると画面が上下 2 つのペインに分かれ、上に「直近」、下に業者シートなど、別々のシート・表示方法を同時に見られます。各ペインの見出しからシート切替と表示方法の変更ができ、境界のバーをドラッグして高さを調整できます（設定は記憶されます）。

そのほか: 全文検索（行・カードを絞り込み）、文字サイズ変更、空行・空列の省略、行番号・列記号の表示、前回ファイルの端末内保存（IndexedDB）と起動時の自動再表示、オフライン動作（Service Worker）。

## 使い方

1. `index.html` を HTTPS で公開します（GitHub Pages なら `Settings → Pages → Branch` を選ぶだけ）。
2. スマホのブラウザで開き、「ファイルを選択」から `.xlsm` / `.xlsx` を選びます。
3. 「ホーム画面に追加」するとアプリのように起動できます。

ローカルで試す場合:

```bash
python3 -m http.server 8080
# → http://localhost:8080/
```

## 構成

```
index.html            画面
css/app.css           スタイル（スマホ縦画面優先）
js/app.js             画面ロジック（日別 / カード / 表）
js/xlsx-lite.js       xlsx/xlsm の軽量リーダー（値・書式・塗り・結合・固定枠・非表示）
js/numfmt.js          Excel 表示形式の整形（m"月"d"日" / aaa 曜日 / ggge 元号 など）
vendor/jszip.min.js   zip 展開（MIT）
sw.js / manifest.webmanifest / icons/   PWA
```

依存ライブラリは JSZip のみで、ビルド工程はありません。対象シートだけを解析するため、数十シート・数千行のブックでも数秒で開きます。

## 制限

- 旧形式 `.xls` は非対応（`.xlsx` / `.xlsm` で保存してください）。
- 数式は Excel が保存した計算結果を表示します（再計算はしません）。
- 条件付き書式・罫線・グラフ・画像は表示しません。
