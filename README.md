# Order View（発注ビューア）

**公開 URL: https://tcta-tottori.github.io/Order/**

Excel の発注ブック（`○○Ver.6.xlsm` など）や在庫一覧をスマートフォンの縦画面で見やすく表示する、インストール不要の Web アプリ（PWA）です。
ファイルはスマホ内（iCloud Drive / Google ドライブ / ファイルアプリ等）から選択し、ブラウザ内だけで解析します。サーバーへの送信はありません。

## 表示対象のシート

**「直近」と、「所要(調整)」より右側にあるシート**（ハコ_直近 / ハコ / ゴウダ / パット_直近 / 各業者…）を表示します。
「所要(調整)」が無い場合は「直近」以降すべてが対象です。設定で「対象外のシートも表示」を ON にすると、設定・在庫警告・所要などもメニューに出せます（選択時に読み込み）。

**在庫一覧シート**（品番の列と `202407` のような月ごとの在庫列が 6 か月分以上あるシート）は自動的に判定され、専用の **在庫チェック画面**（下記）で開きます。発注ブックとは別の、在庫一覧だけの単独ファイルでもそのまま開けます。

## 画面構成

- **ヘッダー**: 左にシート名、その下に現在のフィルター状況（検索・列フィルター・L/T フィルター・変更件数）、右に行数。
- **左上 ≡（ハンバーガー）**: 左からメニューが開き（開くと ✕ に変わり、押すと閉じます）、シートの一覧・変更内容・読み込みページ・設定・バージョン情報を選べます。アプリ名は下部に小さく表示。
- **右下 ✎（編集ボタン）**: 表示メニューが**画面の下寄り（高さ 80%）**に開き、表示方法（日別 / 在庫 / カード / 表）の切り替え、検索、列フィルターの解除、L/T フィルター、表の列の表示/非表示を編集できます。文字を入力すると**上部を少しだけ残してソフトキーボードの上まで広がる**ので、入力欄も一覧もボタンも隠れません。表示方法を選ぶとメニューは閉じ、すぐ結果を確認できます。
- 配色は Excel の緑を基調にしています。

## 在庫チェック（在庫一覧シート）

1 品番 = 1 カードで、**機種名（代表機種）をいちばん大きく**表示し、その下に品番・品名を置きます。続けて **帳簿在庫（最終月）・在庫金額・単価**、月ごとの在庫推移をスパークラインで示します。カードには区分バッジ、担当・手配先・管理部署・入庫日／出庫日・入数、備考や項目、品番が並ぶ備考列（関連品番）が入ります。「明細を表示」で全 25 か月などの在庫推移の一覧と、残りの列をすべて開けます。

- **実棚数の入力**: カードの「実棚」の行を押すと入力パネルが開きます。**箱（パッキンケース等）は 1 綴り = 10 個** が既定で、**綴り数**と**端数**を ± ボタンで入れると合計が自動計算されます（例: 5 綴り + 3 = 53 個）。1 綴りの個数はその場で変更でき、品番ごとに記憶します。箱以外で「入数」がある品番は入数をまとめ単位（ケース）に使い、どちらでもない品番は個数だけの入力になります。帳簿在庫との**差異**がその場に出ます。
- **1 タップで「帳簿どおり」**: 数が合っている品番は、カード左の ✓ を押すだけで「帳簿どおり数えた」として記録されます（もう一度押すと取消）。数が違う品番だけ実棚を入力すれば済みます。
- 上部に `実棚入力 12 / 114` と進捗バー、ヘッダーに入力件数と差異件数が出ます。入力は品番をキーに端末内へ保存され、元の Excel ファイルには手を加えません。「絞り込み」の中の「実棚の入力をすべて消す」でまとめて消せます。
- **並び替え**: **機種順** / Excel 順 / 金額順 / 在庫数順 / **差異順** / 動きなし順 / 品番順。機種順にすると機種名の見出し（`NJ-SE06F　2品番`）が入り、機種ごとにまとまって見えます。
- **絞り込み**: **機種**・区分・担当・手配先・管理部署・備考・項目を、件数つきのチップから複数選択できます。「未入力のみ」「差異あり」「動きなし（6 か月以上、在庫数が変わっていない品番）」はワンタップで切り替えられます。✎ メニューの検索も併用できます。
- **Excel の絞り込み**: オートフィルターを掛けたまま保存されたファイルは、Excel と同じく隠れた行を除いて表示します。隠れている件数は `Excel非表示 +92` のチップに出て、押すと全品番を表示できます。
- 上部には、絞り込み後の **品番数と在庫金額の合計** が常に出ます。

帳簿在庫は最終月の列、在庫金額は「金額」列の値をそのまま使います（再計算はしません）。

### 報告資料の出力

上部の **「報告資料」** を押すと、棚卸の集計（対象件数・入力済み・未入力・差異あり件数、帳簿と実棚の数量合計、**箱の綴り合計**、帳簿金額・実棚金額・差異金額）が出ます。そのまま **Excel を添付してメール（共有）** または **Excel を保存** できます。出力される Excel は 2 シートです。

| シート | 内容 |
| --- | --- |
| 棚卸結果 | 1 行 = 1 品番。**代表機種**・品番・品名・区分・担当・手配先に加え、**単位（綴り/ケース/個）・1 単位の個数・綴り数・端数・実棚(個)・帳簿(個)・差異(個)**、単価・帳簿金額・実棚金額・差異金額、状態（一致 / 差異 / 未入力）・備考 |
| サマリー | 進捗・数量・箱の綴り合計・金額の集計 |

絞り込み中はその品番だけが対象になります（パネルにも注意書きが出ます）。

## 数量の変更と共有

- 業者シートの表で **「所要」「発注」の数量セルをタップ** すると数量を変更できます（±ボタン、最小ロット単位の加減、0 にする）。変更セルはオレンジ、その影響で再計算された **在庫（当日以降）は青** で表示され、元の値も小さく残ります。
- 変更は端末に記憶され、元の Excel ファイルには手を加えません。
- メニューの **「変更内容」** に全変更が一覧され、個別の取り消し・全破棄ができます。「Excel を添付してメール（共有）」で変更一覧の Excel（見やすい「変更一覧」＋マクロ反映用の「取込用」シート）を作成し、端末の共有機能からメール等に添付できます。共有に対応していない環境では Excel を保存し、件名・本文入りのメール作成画面を開きます。

## 発注L/T の補完

「発注L/T」が 0 または空白の品番は、同じシート内の **同じ代表機種 → 品名が近い（先頭が一致する）品番 → シート内の最長 L/T** の順で L/T を推定し、L/T×2 フィルターに使います。✎ メニューに推定件数を表示します。

## 画面の向き

設定の「画面の向き」で **端末の設定に従う / 回転しない（縦固定） / 横向き固定** を選べます。横向きでは分割ビューが左右に並び、カードや日別表示が 2 列になります（PWA として追加している場合は OS の回転ロック、それ以外はアプリ内で画面を回転します）。

## 3 つの見方

| 見方 | 内容 |
| --- | --- |
| 日別 | 「直近」のような **出荷日ごとのブロック × ライン** 構成のシートを自動判定し、日付を選ぶとライン別に機種・色・数量・備考・残業状況をカードで表示 |
| カード | 見出し行のある一覧シートを 1 行 = 1 カードで表示。品番・品名をタイトルに、日付列は「日別」チップ（0 と空欄は省略）にまとめます。「所要」のように 所要/発注/在庫 が連続する行は 1 枚に統合 |
| 表（直近） | 「直近」では **出荷日 × ライン のマトリクス**。各セルに機種・色・数量のチップと残業/定時/停止のバッジ、今日の列を強調。6 件以上は「+N件を表示」で展開。元の Excel レイアウトは「Excel」ビューで確認可 |
| 在庫 | 在庫一覧シートを **1 品番 = 1 カード** で表示。在庫数・在庫金額・在庫推移のグラフ・動きなし月数を並べ、確認できた品番にチェックを付けられます（後述） |
| 表 | 業者シートでは **品番・品名（と区分）を左に固定** し、他の属性列は初期状態で非表示（✎ メニューから列ごとに表示/非表示を切替、シートごとに記憶）。「当日」から先の日付列は横スクロールで閲覧。今日の日付列は強調表示。その他のシートは Excel のレイアウトどおり（固定枠・結合セル・塗り色・非表示行列を反映）。ピンチで拡大縮小、セルをタップで品番・区分・日付つきの全文表示 |

**フィルター（業者シートの表・カード）**: Excel と同じように **表の見出しセルをタップ** すると、その列の値一覧（件数つき）が**画面の下寄り（高さ 80%）**に開き、複数選択・値の検索・「空白・0 を除く」・数値の範囲（以上/以下）で絞り込めます。文字を入力すると**上部を少しだけ残してソフトキーボードの上まで広がる**ので、検索欄・一覧・「適用」がキーボードに隠れません。**値を検索してから一覧の値をタップすると、その列の他の値はすべて選択解除**され、その値だけで絞り込まれます（続けて別の値をタップすれば追加選択になります）。選択数は一覧の上に「選択 2 / 22 件」と出ます。日付列では「この日に発注あり / 所要あり」を選ぶと、その日に発注（所要）がある品番の所要・発注・在庫の 3 行をまとめて表示できます。複数の列に同時に設定でき、絞り込み中の見出しは緑にフィルターマークが付きます。✎ メニューには設定中のフィルターが一覧表示され、個別／一括で解除できます。「L/T×2 フィルター」（発注L/T×2 営業日以内に所要・発注がない品番を隠す。初期状態 ON）は ✎ メニューで切り替えます。日付見出しは上段「9/7」、下段が曜日で、土日は色分け、今日は緑で強調されます。

**分割ビュー**: ✎ メニューの「分割ビュー」を ON にすると画面が上下 2 つのペインに分かれ、上に「直近」、下に業者シートなど、別々のシート・表示方法を同時に見られます。各ペインの見出しからシート切替と表示方法の変更ができ、境界のバーをドラッグして高さを調整できます（設定は記憶されます）。

そのほか: 全文検索（行・カードを絞り込み）、文字サイズ変更、空行・空列の省略、行番号・列記号の表示、前回ファイルの端末内保存（IndexedDB）と起動時の自動再表示、オフライン動作（Service Worker）。

## アプリの更新

公開側に新しい版が出ると、アプリを開いた（またはホーム画面から復帰した）ときに自動で確認し、**上部に「新しいバージョン v1.7.3 があります」の緑のバー**が出ます。「更新」を押すとキャッシュを作り直して最新版を読み込みます（取り込んだ Excel・変更内容・チェックは消えません）。
何も操作していないときは、そのまま自動で最新版に切り替わります。メニューの「バージョン情報」にも **公開中の最新版**と「更新を確認」「今すぐ最新版にする」があり、いつでも手動で最新にできます。

ホーム画面に追加した PWA は復帰時にページが再読み込みされないため、以前は古い版のまま使い続けてしまうことがありました。復帰のたびに版を確認することでこれを解消しています。

## 使い方

1. `index.html` を HTTPS で公開します（GitHub Pages なら `Settings → Pages → Branch` を選ぶだけ）。
2. スマホのブラウザで開き、「ファイルを選択」から `.xlsm` / `.xlsx` を選びます。
3. 「ホーム画面に追加」するとアプリのように起動できます。

ローカルで試す場合:

```bash
python3 -m http.server 8080
# → http://localhost:8080/
```

## 構成

```
index.html            画面
css/app.css           スタイル（スマホ縦画面優先）
js/app.js             画面ロジック（日別 / 在庫 / カード / 表）
js/xlsx-lite.js       xlsx/xlsm の軽量リーダー（値・書式・塗り・結合・固定枠・非表示）
js/numfmt.js          Excel 表示形式の整形（m"月"d"日" / aaa 曜日 / ggge 元号 など）
vendor/jszip.min.js   zip 展開（MIT）
sw.js / manifest.webmanifest / icons/   PWA
```

依存ライブラリは JSZip のみで、ビルド工程はありません。対象シートだけを解析するため、数十シート・数千行のブックでも数秒で開きます。

## 制限

- 旧形式 `.xls` は非対応（`.xlsx` / `.xlsm` で保存してください）。
- 数式は Excel が保存した計算結果を表示します（再計算はしません）。
- 条件付き書式・罫線・グラフ・画像は表示しません。
