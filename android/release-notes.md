## Order View v__VERSION__（Android アプリ版）

下の **Assets** にある `__APK__` を Android 端末でダウンロードして開くと入ります。

### 入れかた
1. `__APK__` をタップしてダウンロード
2. 「提供元不明のアプリ」の確認が出たら、Chrome（またはファイル管理アプリ）に許可を与える
3. そのままインストール。すでに入っている場合は上書きされ、取り込んだファイルと変更内容は残ります

### このアプリについて
- 画面一式を APK に同梱しているので、**通信なしで動きます**（Excel の解析も端末内だけ）
- 通信するのは「新しい版が出ていないか」を確かめるときだけです
- 新しい版が出ると、起動時に画面上部へお知らせが出ます。「入手」を押すとこのページが開きます
- 「バージョン情報」で、いま入っている版と公開中の最新版をいつでも見比べられます
